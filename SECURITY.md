# Security Policy

## Reporting a vulnerability

Please do not publish exploitable file-handling vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature when it is available for the repository.

Include:

- A description of the problem
- Steps to reproduce it
- The affected operating system and Bash version
- The potential effect on user files
- A suggested fix, if known

Avoid testing with irreplaceable files. Use a temporary directory and backups.
